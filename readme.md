# 📖 Description

**MY BOOKINGS** is a frontend-only bus booking website designed to demonstrate how a modern online bus-booking platform can work.

Users can:

1. Select their location.
2. Enter From and To locations.
3. Select a journey date.
4. Search for available buses.
5. View bus details.
6. View routes, facilities, and ticket pricing.
7. Select available seats.
8. Select a demo payment method.
9. Complete a simulated payment.
10. View booking confirmation details.

The complete booking flow is implemented on the frontend.
